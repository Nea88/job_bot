# Job Bot

Раз в час собирает вакансии с hh.ru, Habr Career, Hirify и Telegram-каналов по фильтрам пользователей,
присылает новые совпадения и собирает тестовые интервью по самым востребованным навыкам.
Требования из вакансий извлекает локальная LLM (аддон **Ollama** из этого же репозитория).

## Установка

1. Установи и запусти аддон **Ollama**.
2. Установи **Job Bot**, во вкладке «Конфигурация» заполни:
   - `bot_token` — токен от @BotFather;
   - `admin_ids` — свой Telegram ID (узнать: @userinfobot).
3. Запусти аддон. В логе должно появиться `found Ollama add-on at ...`. При первом старте
   модель скачивается сама (около 2 ГБ для `qwen2.5:3b`), это займёт несколько минут.
4. Напиши боту `/start`, затем `/filters` → «Новый фильтр».

## Raspberry Pi

- Нужна Pi 4/5 с 8 ГБ RAM. Модели крупнее 3B на Pi работают слишком медленно.
- Анализ одной вакансии занимает около минуты, генерация интервью — несколько минут.
- Если есть компьютер мощнее, запусти Ollama на нём и укажи `ollama_url: http://<ip>:11434`
  с моделью `qwen2.5:7b-instruct`. Аддон Ollama тогда не нужен.

## Telegram-каналы (опционально)

Каналы читаются через обычный аккаунт Telegram:

1. Получи `api_id` и `api_hash` на https://my.telegram.org.
2. На компьютере с клоном репозитория выполни (в `.env` должны быть `TG_API_ID`, `TG_API_HASH`, `BOT_TOKEN`):
   ```bash
   uv run python scripts/telethon_login.py --string
   ```
3. Вставь `tg_api_id`, `tg_api_hash` и полученную строку в `tg_session_string`, перезапусти аддон.
4. Добавь каналы командой `/channels add <username>`.

## hh.ru

hh.ru требует User-Agent с контактом: укажи в `hh_user_agent` что-то вроде
`JobBot/1.0 (твой@email)`. Шаблонные значения hh блокирует, а без этой настройки hh.ru пропускается.

Если в логе `403 forbidden` от hh.ru, зарегистрируй приложение на https://dev.hh.ru и укажи его
токен в `hh_access_token`.

## Данные

База и сессии хранятся в `/data` аддона и попадают в бэкапы Home Assistant.
