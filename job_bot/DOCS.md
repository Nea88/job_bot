# Job Bot

Раз в час собирает вакансии с hh.ru, Habr Career, Hirify и Telegram-каналов по фильтрам пользователей,
присылает новые совпадения и собирает тестовые интервью по самым востребованным навыкам.
Требования из вакансий извлекает локальная LLM (аддон **Ollama** из этого же репозитория).

## Установка

1. Установи и запусти аддон **Ollama**.
2. Установи **Job Bot**, во вкладке «Конфигурация» заполни:
   - `bot_token` — токен от @BotFather;
   - `admin_ids` — свой Telegram ID (узнать: @userinfobot).
3. Запусти аддон. В логе должно появиться `found Ollama add-on at ...`. При первом старте
   модель скачивается сама (около 2 ГБ для `qwen2.5:3b`), это займёт несколько минут.
4. Напиши боту `/start`, затем `/filters` → «Новый фильтр».

## Raspberry Pi

- Нужна Pi 4/5 с 8 ГБ RAM. Модели крупнее 3B на Pi работают слишком медленно.
- Анализ одной вакансии занимает около минуты, генерация интервью — несколько минут.
- Если есть компьютер мощнее, запусти Ollama на нём и укажи `ollama_url: http://<ip>:11434`
  с моделью `qwen2.5:7b-instruct`. Аддон Ollama тогда не нужен.

## Telegram-каналы (опционально)

Каналы читаются через обычный аккаунт Telegram (можно завести отдельный):

1. Получи `api_id` и `api_hash` на https://my.telegram.org → API development tools
   (название и короткое имя приложения любые, платформа Desktop). Если форма отвечает «ERROR»,
   попробуй другой браузер или без VPN.
2. Впиши их в `tg_api_id` и `tg_api_hash` и перезапусти аддон.
3. Отправь боту `/tglogin` и следуй подсказкам: номер телефона, код из Telegram
   (**с пробелами**, например `1 2 3 4 5`, иначе Telegram аннулирует код) и облачный пароль,
   если включена двухэтапная проверка. Сообщения с кодом и паролем бот сразу удаляет.
   Если код не приходит (Telegram иногда не доставляет коды сторонним приложениям), отправь
   `/tgqr`: бот пришлёт QR-код. Открой его на другом экране (Telegram Desktop или web.telegram.org)
   и отсканируй телефоном: Telegram → Настройки → Устройства → «Подключить устройство».
4. Добавь каналы: `/channels add t.me/name` (можно несколько через пробел).

Сессия хранится в `/data` аддона. Отозвать доступ: Telegram → Настройки → Устройства.
Вместо `/tglogin` можно вставить строку сессии в `tg_session_string`
(`uv run python scripts/telethon_login.py --string` на компьютере).

## hh.ru

hh.ru требует User-Agent с контактом: укажи в `hh_user_agent` что-то вроде
`JobBot/1.0 (твой@email)`. Шаблонные значения hh блокирует, а без этой настройки hh.ru пропускается.

Без токена hh.ru показывает капчу уже после первого запроса (в логе `403 forbidden`),
поэтому нужен токен приложения:

1. Зарегистрируй приложение на https://dev.hh.ru → «Мои приложения». Redirect URI любой,
   например `https://localhost`. Дождись одобрения.
2. На компьютере с клоном репозитория выполни:
   ```bash
   uv run python scripts/hh_app_token.py <client_id> <client_secret>
   ```
3. Вставь полученный токен в `hh_access_token` и перезапусти аддон. Токен бессрочный.

## Данные

База и сессии хранятся в `/data` аддона и попадают в бэкапы Home Assistant.
