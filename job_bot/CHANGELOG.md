# Changelog

## 0.2.2

- hh.ru: без токена приложения поиск упирается в капчу (403), теперь это понятное сообщение
  в логе; скрипт `scripts/hh_app_token.py` получает токен по client_id/client_secret.

## 0.2.1

- hh.ru: убран шаблонный User-Agent, который hh блокирует. Без своего `hh_user_agent`
  с email hh.ru пропускается с понятным сообщением в логе вместо ошибок.

## 0.2.0

- Новый источник: hirify.me (главная и страницы категорий, полное описание из JobPosting).
  В существующие фильтры со всеми источниками Hirify добавляется автоматически.
- LLM анализирует только вакансии, совпавшие с чьим-то фильтром, иначе очередь на Pi не разгребается.

## 0.1.2

- hh.ru: формат работы передаётся через `work_format` (старый `schedule` hh отклонял с 400),
  в лог пишется причина отказа hh.
- Зарплата в фильтре: понимает «300к», числа меньше 1000 считаются тысячами;
  уже сохранённые фильтры исправляются автоматически.

## 0.1.1

- Исправлен автопоиск аддона Ollama: адрес берётся из префикса репозитория,
  поиск повторяется, пока Ollama не появится; в логе виден адрес подключения.

## 0.1.0

- Первый релиз: сбор вакансий hh.ru / Habr Career / Telegram, фильтры, анализ требований
  через Ollama, тестовые интервью.
