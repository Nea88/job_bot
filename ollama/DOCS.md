# Ollama

Локальная LLM-модель для аддона Job Bot. Это облегчённая сборка Ollama только для процессора, без GPU-библиотек. Настройки не нужны: Job Bot сам находит этот аддон
и скачивает нужную модель при первом запуске. Модели хранятся в `/data/models` аддона.

Порт 11434 по умолчанию закрыт снаружи. Открой его во вкладке «Сеть», чтобы обращаться
к модели из локальной сети.

На Raspberry Pi нужна 8 ГБ RAM. Если в бэкапы не должны попадать гигабайты моделей,
исключай этот аддон из бэкапа.
